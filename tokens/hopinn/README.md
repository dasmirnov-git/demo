# Hopinn custom scales

12-step scales generated beside stock Radix (`tokens/radix/` is untouched).

- Contract: [Radix Understanding the scale](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) (steps 1–12 use cases).
- Method: remap a stock Radix template’s lightness ramp onto the etalon solid (hue/chroma), then pin brand anchors. In light mode, interpolate Purple 3–8 and 10–12 and Gold 6–9 in OKLab to avoid lightness reversals. Neutral keeps the stock intermediate steps.
- Regenerated by `node design-system/scripts/generate_hopinn_scales.mjs`.

Do not hand-edit the CSS files.
